📊 全品种 · 全合约

中金所、上期所、郑商所、大商所、上期能源、广期所，覆盖上市以来全部合约（含已到期退市），不只是主力连续。

🖥️ 本地网页界面

勾选参数、点开始、实时看日志与进度。结果以 KPI 卡片、汇总表、K 线图呈现，无需命令行。

📈 交互式 K 线图

拖拽平移、滚轮缩放、十字光标、双击复位；自动标注历史最高/最低价及其日期，一键跳转定位。

🧮 五种技术指标

MA、EXPMA、BOLL、BBIBOLL、SAR 可任意勾选叠加，全部在浏览器本地计算，切换零延迟、断网可用。

🗓️ 按月分组对比

按交割月份分组，跨年同月合约归为一组。例如沪金 6 月组会把 AU0806 到 AU2706 放在一起对比。

⚖️ 加权合约

按各合约持仓量加权合成一条无换月跳空的连续序列，用于观察品种整体价格水位。

💾 免重复抓取

可指定本地数据目录直接载入已有结果，也可以让程序记住上次的数据 —— 重启后零操作恢复，不再重新下载。

📁 原生对话框保存

弹系统原生文件夹对话框选择本机保存位置，一键导出 Excel / CSV（UTF-8 BOM，中文不乱码）。

⚡ 增量缓存

每个交易所一个缓存文件。首次慢、之后快；中断也保留已完成部分，下次自动跳过。

1快速开始

  1. 到 Releases 下载 FuturesWorkbench-v1.0.0-win64.exe，放到任意目录（如 D:\FuturesWorkbench\）。
  2. 双击运行。首次启动会解包依赖，约需 10～40 秒。
  3. 程序自动打开浏览器并跳转到 http://127.0.0.1:8770。若没自动打开，手动访问该地址即可。
  4. 左侧勾选交易所与品种（并发线程建议调到 16），点「开始抓取」。
  5. 首次全量抓取约需 1 个半小时。之后再次运行会自动增量更新，通常几分钟内完成。
  6. 在「品种详情」看 K 线，或点底部「保存到本机」导出 Excel / CSV。
⚠
关闭控制台窗口 = 停止服务

程序运行期间请保留那个黑色控制台窗口。它是服务进程本体，窗口关掉网页就打不开了。

2运行方式

方式适合做法
exe 不想装 Python 下载后双击 FuturesWorkbench-v1.0.0-win64.exe
源码 想看代码 / 二次开发 pip install -r requirements.txt 然后 python app.py（Windows 可直接双击 启动.bat）
本地数据模式 已有数据、不想重抓 左侧「本地数据」选择目录 → 「载入本地数据」。程序也会在启动时自动恢复上次数据。

4注意事项

  • 首次很慢是正常的。六家交易所、20 年历史、上百万条记录需要逐日请求，请保持窗口开启。
  • 别删缓存目录。删了下次就要重新全量抓取。
  • 数据不是实时的。日K要在收盘结算后才公布，盘中抓到的当日数据不完整。本工具定位是历史研究，不适用盘中交易决策。
  • 不要暴露公网。服务没有认证机制，只监听 127.0.0.1。如需多人使用请放在内网并加身份验证。
  • 极值基于全部合约。会包含流动性差的远月合约，可能拉高最高价。要看主力口径请用「加权合约」视图。
  • 主连不做复权。换月处存在跳空，不能直接用来算收益率或做回测。
